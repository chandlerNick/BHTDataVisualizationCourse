# BHT DataVisualizationCourse

In this report, we do analysis (primarily visual) on data about the world. Our goal was to answer 5 questions about the dataset we had and the final report is in `CombinedReport.pdf`.

The main skills developed were: Data visualization techniques, R programming, data cleaning, exploratory data analysis, & report writing.

The report was done entirely in R with some python used in the early stages of the project. We used a dataset that required a bit of cleaning (a scrape of the CIA world factbook website) so there is string cleaning and unit conversion in the source code for each of the files.

The data is available in the `data` directory and the code associated with each question is available in any of the `QuestionX` directories.
